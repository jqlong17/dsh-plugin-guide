# dsh 插件开发指南

写给想给 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（dsh）写插件的人：从最小可运行插件，到带前端面板、本地引擎和发布流程的完整插件。

> 适用版本：dsh `0.2.2-rc.1`（2026-11）。插件 API 仍在演进，升级 dsh 后请先对照官方文档。

## 这本指南解决什么

- 插件由哪些文件组成，dsh 怎么加载它；
- host 工具、client 槽位、构建产物三者的硬约束；
- 本地怎么装、为什么“装了不生效”、怎么排查；
- 带本地进程/持久化/后台任务时怎么做才不坑；
- 怎么测试、怎么发布、怎么兼容不同 dsh 版本。

不包含：dsh 本体开发、UI 设计规范、模型能力调优。

## 最小模板

[`scaffold/`](scaffold/) 是一个可直接复制的插件模板：一个 host 工具 + 一个主区面板。

```bash
cp -R scaffold my-plugin
cd my-plugin && npm install && npm run build
dsh plugin --profile web add "link:$PWD"
# 重启 dsh
```

模板里的代码在 [00 快速开始](00-快速开始.md) 有逐段解释。
